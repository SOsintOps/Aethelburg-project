# 3. Timeline & FT3 Matrix

## Timeline

Dated events of the selected company: incorporation, dissolution, name changes, PSC notifications and cessations, officer appointments and resignations, sanctions designations. Each line shows the date, the event type, a description and the source dataset.

Changes Aethelburg observed between two updates are listed too (`ADDRESS_CHANGED`, `STATUS_CHANGED`, `SIC_CHANGED`, `ACCOUNTS_FILED`, …) with *old → new* and the date they were observed; the date shown is the date of effect when Companies House gives one (dissolution, accounts made up to). See [Recent changes](data-and-updates). Once the filing history has been downloaded (**Update from CH**) every filing is a `FILING` event with its form type.

## FT3 matrix

All eleven FT3 shell-company techniques used by Aethelburg, with the ones triggered for the selected company highlighted. Each card shows the priority, the FT3 tactic, the evidence found and the **innocent explanations**: the lawful reasons that can produce the same pattern. A triggered technique is an investigative lead, not a finding. See [Risk scoring](risk-scoring).
